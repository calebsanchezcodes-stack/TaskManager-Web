# TaskManager Web

Aplicación web sencilla para registrar actividades pendientes, marcarlas como completadas y eliminarlas.

## Objetivo
Practicar el desarrollo colaborativo con Git y GitHub (ramas, pull requests y resolución de conflictos) construyendo una aplicación web con HTML, CSS y JavaScript.

## Instrucciones de ejecución
1. Clonar el repositorio: git clone https://github.com/calebsanchezcodes-stack/TaskManager-Web.git
2. Entrar a la carpeta: cd TaskManager-Web
3. Abrir index.html en el navegador.

## Funciones
- Agregar una tarea desde el formulario.
- Marcar una tarea como completada.
- Eliminar una tarea.
- Diseño responsivo para celular y computadora.

## Flujo de trabajo: GitHub Flow
Se usó GitHub Flow porque el proyecto es pequeño y este flujo es simple: main siempre tiene código funcional, cada función se desarrolla en su propia rama y se integra con un pull request.

1. Crear una rama desde main (git switch -c feature/nombre).
2. Hacer commits descriptivos en la rama.
3. Subir la rama (git push -u origin feature/nombre).
4. Abrir un pull request hacia main.
5. Revisar y comentar los cambios.
6. Fusionar el pull request y actualizar main (git pull).

Ramas de funcionalidad: feature/interfaz, feature/tareas y feature/estilos. Para practicar la resolución de conflictos se usaron prueba/rama-a y prueba/rama-b.
